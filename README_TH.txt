# Student Council Portal — Green & Gold

เว็บไซต์สภานักเรียน มีเพียง 2 บทบาท:
1. ประธานนักเรียน — จัดการงาน มอบหมายงาน และตรวจสอบรายงาน
2. กรรมการสภานักเรียน — ดูงานที่ได้รับมอบหมายและอัปเดตความคืบหน้า

## ไฟล์
- `index.html` หน้าเว็บไซต์
- `style.css` ธีมเขียวมรกต–เหลืองทอง รองรับมือถือและคอมพิวเตอร์
- `app.js` กิจกรรมตัวอย่างและแบบฟอร์มเพิ่มกิจกรรมแบบชั่วคราว
- `firebase-config.example.js` ตัวอย่างการตั้งค่า Firebase

## สำคัญ
เวอร์ชันนี้เป็นหน้าเว็บต้นแบบ การล็อกอินและฐานข้อมูลจริงยังไม่ได้เชื่อมต่อ การเพิ่มกิจกรรมยังไม่ซิงก์ข้ามอุปกรณ์

ก่อนใช้งานจริงต้องตั้งค่า Firebase Authentication, Firestore และ Security Rules โดยให้สิทธิ์ประธานและกรรมการจากข้อมูลบทบาทที่เชื่อถือได้ ห้ามให้ผู้ใช้กำหนดบทบาทผู้ดูแลตัวเองจากแบบฟอร์มสมัครสมาชิก
